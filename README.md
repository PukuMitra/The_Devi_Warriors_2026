# 🌺 The Devi Warriors 2026

### ✨ Subho Saradiya | Celebrating the Spirit of Durga Puja

Welcome to **The Devi Warriors 2026** — a festive website created to celebrate the spirit, beauty, and cultural significance of **Durga Puja**. This project brings together creativity, technology, and tradition to create a digital festive experience.

🔗 **Live Website:** [https://pukumitra.github.io/The_Devi_Warriors_2026/](https://pukumitra.github.io/The_Devi_Warriors_2026/)

---

## 🪔 About the Project

**The Devi Warriors 2026** is a festive web project presented by the students of the **Department of Artificial Intelligence and Data Science** at **Swami Vivekananda Institute of Science & Technology**.

Inspired by the power and grace of Goddess Durga, the website celebrates the festive spirit of *Sharodiya Durga Puja* through a creative digital experience.

The project combines web development with Bengali cultural traditions to share festive greetings and showcase the identity of the Devi Warriors team.

---

## 🎯 Objectives

- Celebrate the cultural heritage and festive spirit of Durga Puja.
- Create an engaging digital experience with a festive theme.
- Showcase creativity and front-end web development skills.
- Represent the identity and teamwork of the Devi Warriors.
- Combine traditional Bengali celebrations with modern web technologies.

## 🚀 Run Locally

To view or modify this project on your computer:

### 1. Clone the repository

```bash
git clone https://github.com/pukumitra/The_Devi_Warriors_2026.git
```

### 2. Navigate to the project folder

```bash
cd The_Devi_Warriors_2026
```

### 3. Open the website

Open `index.html` in your browser.

Alternatively, open the project folder in Visual Studio Code and use the Live Server extension for local development.
